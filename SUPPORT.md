# Support

Most CPMForge source repositories are private, so this repository is the
public place to report problems and ask questions — whatever the project.

## Where to go

| You want to | Go to |
| --- | --- |
| Report a bug | [New issue](https://github.com/cprima-forge/.github/issues/new/choose) |
| Ask how something works, or propose an idea | [Discussions](https://github.com/cprima-forge/.github/discussions) |
| Report a security vulnerability | See [SECURITY.md](SECURITY.md) — **not** a public issue |

## What to include

An issue is far easier to act on with:

- **which** extension or library, and its **version** (the Extensions pane
  shows it; a package listing shows it)
- what you expected, and what happened instead
- for an editor extension: the host it runs in, since an embedded editor and
  desktop VS Code differ in both API surface and version
- if the problem involves a workflow file, the smallest fragment that shows
  it — with anything client-identifying removed

Please do not paste customer project names, file paths, or workflow contents
you are not free to share. A reduced sample is more useful anyway.

## What to expect

This is worked on alongside other things. Issues are read; not all of them
get fixed, and some are closed as out of scope. If something is urgent for
you, say so and say why — it does affect ordering.
