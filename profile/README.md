# CPMForge

Developer tooling for low-code RPA: libraries, packaging, and editor
extensions for XAML workflow projects.

Most work here is built as a spike first and promoted once it earns it, so
you will find things at very different stages of maturity.

## Where things are published

| What | Where |
| --- | --- |
| VS Code extensions | [Open VSX](https://open-vsx.org/namespace/cpmforge) |
| Automation libraries | a package feed, per project |

Extensions target the editor embedded in low-code designers, which installs
from Open VSX rather than the Microsoft Marketplace.

## Reporting something

**Issues and questions belong here**, in this repository, whichever project
they concern — most source repositories are private, so this is the public
front door.

- [Report a bug](https://github.com/cprima-forge/.github/issues/new/choose)
- [Ask or discuss](https://github.com/cprima-forge/.github/discussions)

Please say which extension or library you mean, and which version.
